# MMD Standard Humanoid Reference Rig

`_model.pmx` is a mesh-free PMX 2.0 reference rig used only for VMD motion
conversion. It is reproducibly generated by
`Tools~/generate-reference-pmx.mjs` and contains:

- standard MMD humanoid bone names and positions calibrated to the local Miku
  compatibility model;
- semi-standard arm/hand twist chains, including the legacy asymmetric elbow
  grant behavior required for existing converted motion compatibility;
- left/right leg IK and toe IK chains;
- common MMD morph names represented by empty vertex morphs;
- one transparent 0.001-unit compatibility triangle and one material, because
  the legacy PMX2FBX backend rejects zero-vertex PMX files;
- no character mesh, textures, materials, physics, trademarks, or
  character-specific bones from that model.

Run the generator from the package root with:

```text
node Tools~/generate-reference-pmx.mjs
```
